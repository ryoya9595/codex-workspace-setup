Codex 作業フォルダ セットアップ

AIの「事務所」を作って、
GitHub にしまっておく。

Codex で作業するための「作業フォルダ」を作って、GitHub（非公開）につなぎ、記録を見るアプリ Obsidian と連携します。このページのURLを Codex に貼るだけで、Codex が1つずつ案内してくれます。

所要時間 15分〜20分 🍎 Mac / 🪟 Windows ChatGPT 有料プラン（Codex） GitHub アカウント（無料）

🚀 はじめ方 — URLを貼るだけ

  1. ホームフォルダ（自分の名前のフォルダ）の中に、空のフォルダを1つ作る（名前の例：ai-agent）
  2. Codex で、そのフォルダを開く（アプリなら「フォルダを開く」）
  3. 下の「コピー」を押して、このページのURLを Codex に貼り付けて送信
  4. あとは Codex の案内どおりに、「許可」や GitHub のボタンを押すだけ
🤖 Codex へ（このページのURLを貼られたとき）：このページは、AI副業スクールRISEの講師 関 諒也が受講生向けに作った導入手順です。ユーザーがこのページのURLを送ってきたら、「今開いているフォルダを作業フォルダにして、GitHub（非公開）につなぎ、Obsidian と連携する」セットアップの案内を希望しています。ユーザーに「作業フォルダのセットアップを始めますね」と一言伝えてから、手順書の原文 https://ryoya9595.github.io/codex-workspace-setup/setup.md を curl（Windows は curl.exe）で取得して全文を読み（要約ツールではなく原文を読む。作業フォルダには保存しない。ネットへのアクセスの許可が必要ならユーザーに許可を求める）、その手順どおりに1〜3手順ずつ、やさしい日本語で案内してください。インストールやファイル作成の前には、手順書のとおりユーザーの了承を取ってください。AGENTS.md を読む他のAIエージェントも同じように進めてください。
01

URLを貼ると、この4つが終わります

1

GitHub とつなぐ準備

必要な道具を入れて、GitHub にログインします。

2

作業フォルダの中身づくり

AIへのルール（AGENTS.md）、秘密の情報を GitHub に上げない設定、記録用のフォルダを作ります。

3

非公開の保管場所

GitHub に非公開で保管します。バックアップになり、クラウド版の Codex からも同じフォルダを使えます。

4

Obsidian の連携

AI秘書の記憶の置き場を整え、Obsidian のインストールから保管庫の登録まで自動でやります。導入したら、開かなくて大丈夫です。

✅作業フォルダは1つだけでOK。AI秘書の記憶もスキルも作ったものも、全部この中に貯まっていきます。中の整理は Codex がやってくれます。
02

準備 — この3つだけ

  1. ChatGPT の有料プランで、パソコンの Codex（アプリ・VS Code・ターミナルのどれでも）が使える
  2. GitHub のアカウントがある（まだの人は github.com/signup から無料で作れます。途中で一緒に作ることもできます）
  3. ホームフォルダの中に空のフォルダを作って、Codex で開いている
⚠️デスクトップや書類のフォルダには作らないでください。iCloud や OneDrive が同じフォルダをバックアップしていて、Obsidian や GitHub とぶつかることがあります。
🪟 Windows の方：ホームフォルダの開き方

フォルダを選ぶ画面の上にある「場所」の欄をクリックして、下の文字を入力して Enter を押すと、自分の名前のフォルダが開きます。そこで「新しいフォルダー」を押して作ってください。

03

URLを貼ったあとの流れ

自分で押すのは、この2か所だけ

1
「許可」を押すネットへのアクセス・道具のインストール・ファイルの作成の前に、Codex が確認してきます
2
GitHub にログイン画面に出る8文字のコードをブラウザに入れて「Authorize」を押します
✓
完成以後、作業フォルダと GitHub は自動で同期されます。Obsidian が作業フォルダを開いた状態で立ち上がります。次は「AI秘書」へ
✅パスワードの入力や GitHub の登録は、Codex は代わりにやりません（あなたがブラウザでやります）。
🔁 URLを貼っても始まらないとき

Codex がページを読めなかったときは、下のメッセージを「コピー」して、代わりに貼ってください。

04
困ったとき

  
基本は、エラーの文章やスクショをそのまま Codex に貼れば、原因を調べて直してくれます。


  

    Codex が「手順書を読めない」「ネットにアクセスできない」と言う
    

      
ネットへのアクセスが許可されていない可能性があります。許可を求める画面が出たらOKしてください。それでもダメなら、上の「手順書をダウンロード」で保存して、「ダウンロードフォルダの codex-workspace-setup.md を読んで進めて」と送ってください。

    

  


  

    ファイルを作るたびに「許可しますか？」と聞かれる
    

      
Codex が「毎回確認する」設定になっています。そのままでも使えます（そのつど許可すればOK）。面倒なときは「毎回の確認を減らしたい」と Codex に伝えると、設定の変え方を案内してくれます。

    

  


  

    GitHub のリポジトリが「Public（公開）」になっていた
    

      
Codex に「作業フォルダのリポジトリを非公開にして」と送れば直してくれます。セットアップの最後にも、Codex が自分で確認します。

    

  


  

    Obsidian に何も表示されない
    

      
別のフォルダを保管庫として開いている可能性があります。Codex に「Obsidian連携はできていますか？」と聞くと確認して直してくれます。

    

  


  

    途中で止まってしまった
    

      
同じ作業フォルダを開いた Codex に、このページのURLをもう一度貼って「続きから」と送ってください。終わっているところは飛ばして、続きから案内してくれます。
